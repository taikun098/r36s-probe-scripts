# r36s-probe-scripts

> **仓库说明**：GitHub 为主库，对外开源展示 → https://github.com/taikun098/r36s-probe-scripts
> Gitee 为国内镜像站，访问加速用 → https://gitee.com/wjk098/r36s-probe-scripts
> 两边内容保持一致；Issue / PR 请走 GitHub，Gitee 侧不单独接受合并。

R36S（RK3326）掌机与机顶盒固件的探测、解包、DTB 分析、PortMaster 移植、Wi-Fi/游戏运行环境排障脚本集。

- `*.py` — 探测/下载/解包/校验类脚本
- `*.sh` — 板端执行脚本
- `*.txt` / `*.json` — 运行输出与目录快照（归档留证）

## 说明

本仓库只收录脚本与文本输出，不含固件镜像本体（原目录中的解包镜像约 9.4 GB，未上传）。
仓库为脱敏存档：账号、密码等凭据已移除，用户名统一替换为 `user`。
